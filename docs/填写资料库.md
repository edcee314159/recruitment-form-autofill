# 填写资料库

在 `个人资料` 的第 2 行填写单值信息。不要增加额外个人资料行。

在 `经历清单` 中一行代表一条独立经历。语言成绩必须一项证书/考试一行，例如 CET-4、CET-6、IELTS 分三行，成绩和证书名称保持在同一行。网站出现“添加语言能力”“增加项目”等按钮时，Skill 会以每行资料对应一个网站条目的方式填写。

日期使用 Excel 日期、`YYYY-MM` 或 `YYYY-MM-DD`；结束时间可以填写“至今”。类别只能使用模板下拉选项。附件清单的本地路径相对于资料库所在目录或使用绝对路径。

每次编辑后运行：

```powershell
python '<公开仓库>\skill\recruitment-form-autofill\scripts\validate_profile.py' --config '<仓库外>\profile-config.json'
```

迁移旧版资料库：

```powershell
python '<公开仓库>\skill\recruitment-form-autofill\scripts\migrate_profile.py' --source '<旧资料库.xlsx>' --destination '<新资料库.xlsx>'
```

迁移只映射新模板定义的字段；未映射内容会以不含原始值的结构提示报告，需手动补充。
