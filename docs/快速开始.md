# 快速开始

本仓库只保存 Skill、空白模板、虚构示例和测试。请把你的资料库、配置文件及附件保存在仓库外。

需要 Python 3.10 或更新版本。先下载或克隆仓库；网页填写还需要安装 `profile-use` 和可用的浏览器控制工具。可复制 `skill/recruitment-form-autofill` 整个目录到 Codex Skills 目录；单独安装后的步骤见 [本地安装与初始化](../skill/recruitment-form-autofill/references/setup.md)。保留已有同名个人 Skill，备份后再选择是否替换。

下面使用独立 Python 环境安装依赖，避免依赖 Codex 的内置环境：

```powershell
$repo = 'C:\path\to\recruitment-form-autofill'
$scripts = "$repo\skill\recruitment-form-autofill\scripts"
$localRoot = 'C:\path\outside-repository\recruitment-local'
python -m venv "$localRoot\.venv"
$profilePython = "$localRoot\.venv\Scripts\python.exe"
& $profilePython -m pip install -r "$repo\requirements.txt"
$profile = 'C:\path\outside-repository\my-profile.xlsx'
$config = 'C:\path\outside-repository\profile-config.json'
& $profilePython "$scripts\init_profile.py" --workbook $profile --config $config
& $profilePython "$scripts\validate_profile.py" --config $config
& $profilePython "$scripts\read_profile.py" --config $config inventory
```

校验无问题时会输出 `{"issues": []}` 并返回 0。完成资料库后，只有在你明确说“帮我填写”时，Skill 才会读取所需字段并填写招聘网页。

旧版资料库可选择迁移到新模板；迁移会写入新的目标文件，绝不覆盖源文件。详见 [填写资料库](填写资料库.md)。
